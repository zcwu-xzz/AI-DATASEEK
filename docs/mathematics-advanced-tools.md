# 数学工具与高维矩阵预览扩展

本次新增 40 个数学工具，数学插件由 34 个扩展至 74 个。当前本地插件注册共 509 个工具，此数量不代表线上已经更新。

## 工具能力

| 类别 | 数量 | 能力 |
| --- | ---: | --- |
| 稀疏矩阵 | 10 | 存储格式转换、重复项及显式零清理、子矩阵提取、算术运算、直接求解、迭代求解、最小二乘、部分特征值、截断奇异值分解、带宽重排序 |
| 矩阵诊断 | 8 | 矩阵性质检查、四个基本子空间、伪逆、行列均衡、低秩近似、分块提取及组合、矩阵比较、线性系统扰动敏感性 |
| 拟合优化 | 8 | 稳健最小二乘、正则化反演、预定义非线性曲线拟合、多项式拟合、标量求根、非线性方程组、线性约束二次目标优化、线性规划 |
| 数值微积分 | 5 | 插值、数值微分、数值积分、线性常微分方程初值求解、二阶线性常微分方程边值求解 |
| 张量分析 | 5 | 模乘积、多线性秩估计、核心张量分解、典型多元分解、张量误差比较 |
| 质量与报告 | 4 | 缺失值处理、异常值检测、重构及线性系统等结果验证、数学分析报告 |

依赖为 NumPy、SciPy、h5py 和 TensorLy；TensorLy 已加入数学插件依赖清单，沙箱镜像构建会安装该清单。

输入通过共同读写层支持 NPY、NPZ、MTX、MAT、HDF5 和数值文本。各工具按向量、矩阵、张量维数及稀疏类型进一步校验。支持 SciPy 稀疏 NPZ 和 MATLAB 7.3 的根级数值变量。

方程表达式为受限数学表达式，不支持任意 Python；非线性拟合模型包括高斯、指数、洛伦兹和逻辑曲线。初值工具处理 `y'=Ay+forcing`，边值工具处理 `y''=Ay`。这些范围不等同于任意非线性微分方程求解。

## 交互预览

支持 NPY、NPZ、MTX、MAT。拖动热力图框选后按原始索引重新读取区域，可恢复完整区域；显示原始坐标、抽样步长、有效点数量、标准差及行列均值剖面。非零结构模式对稀疏矩阵采用分箱占用显示，避免概览遗漏不在抽样网格上的非零项。

三维数组展示三个正交切面，点击切面可更新其余切片的定位；固定轴支持切片播放、暂停和速度选择。切换文件、变量或卸载预览会停止播放，过期请求不会覆盖新内容。

结果容器内的 `S`、`singular_values`、`eigenvalues`、`residual_history` 数值变量可展示奇异值谱、已保存奇异值的累计能量比例、复特征值分布和迭代残差。多数组结果应保存为 NPZ、MAT 或 HDF5 以保留附加数据；当前在线矩阵预览入口支持前述四种格式。

## 边界

- 文件缓存上限 128 MiB，预览按当前用户及文件绑定；不向浏览器返回真实文件路径。
- NPY 使用只读内存映射，MATLAB 7.3 按切片读取。压缩 NPZ 和旧 MAT 需要在限定大小内解码，不能保证对这些格式直接进行磁盘区域随机读取。
- 每轴默认最多 256 个显示点；区域超过显示上限时统计及剖面基于显示样本，界面标注抽样。缩小至上限内可查看该区域完整数值。
- 结果曲线单数组最多 4096 个元素，避免超大结果阻塞预览。
- 求解器返回状态和残差，未收敛不应被解释为有效解；不满足维度或数值条件时返回明确错误。
